# Support

## Supported public surface

TKP Decision and Authority Intelligence is a public product component for evidence-linked extraction and classification of operator decisions, authority, boundaries, and review candidates from normalized conversation records.

For ordinary usage questions and reproducible, non-sensitive defects, use this repository's GitHub Issues.

Please include:

- the normalized input shape used, without private conversation content;
- the command or workflow attempted;
- Python and operating-system versions when relevant;
- the observed result and expected result; and
- a minimal sanitized reproduction when possible.

## Do not post

Do not place private conversation data, credentials, access tokens, client material, local private paths, or other sensitive source material in public issues.

Security- or privacy-sensitive handling follows [SECURITY.md](SECURITY.md).

## Current boundary

Support does not imply live conversation acquisition, raw-export normalization, automatic promotion of natural-language authority candidates, assistant authority, or proof that a command was executed. Those capabilities are outside this repository's current public contract.
